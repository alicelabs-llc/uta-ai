# MarketNow — Universal Trust Adapter & Sentinel catalog (agent index)

> Trust infrastructure for AI agents. UTA translates between 9 agent-credential
> formats (ATC v3, JWT/OAuth, W3C VC, A2A Agent Card, EAT-AI, ZTA, MCP Server Card,
> X.509, + bridge) with a fail-closed 12-stage pipeline. Sentinel certifies MCP
> skills: 71,198 index-certified (L1) as of 2026-10-20 (/api/skills), agent card v4.0.0.
> Generated by scripts/generate_llms_txt.py from live sources (sitemap + APIs).
